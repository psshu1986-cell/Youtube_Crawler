🔌API 接口文档

展开
POST /api/search

搜索 YouTube 视频，返回五个维度的排行数据。

请求头

Content-Type: application/json

请求参数 (JSON Body)

参数类型默认值说明
keywordsstring[]预设关键词列表搜索关键词数组
risingDaysnumber60上升榜统计天数范围
maxPerKeywordnumber30每个关键词最多返回条数
searchLangstring"zh""zh" 中文关键词 / "en" 英文关键词

返回格式

{
  "topViewed": [...],     // 按观看数排序
  "topLiked": [...],      // 按点赞数排序
  "topCommented": [...],  // 按评论数排序
  "topEngaged": [...],    // 按互动率排序
  "topRising": [...],     // 按日均观看排序
  "totalViewed": 200,
  "totalRising": 150
}

调用示例

curl -X POST {{ api_base }}/api/search \
  -H "Content-Type: application/json" \
  -d '{
    "keywords": ["Chinese mythology", "Nezha"],
    "risingDays": 30,
    "maxPerKeyword": 10,
    "searchLang": "en"
  }'
