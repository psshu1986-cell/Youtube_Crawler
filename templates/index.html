🔌API 接口文档

展开
POST /api/search

搜索 YouTube 视频，返回最多观看和上升最快排行数据。

请求头

Content-Type: application/json

请求参数 (JSON Body)

参数类型默认值说明
keywordsstring[]预设关键词列表搜索关键词数组，如 ["哪吒", "二郎神"]
risingDaysnumber60上升榜统计天数范围
maxPerKeywordnumber30每个关键词最多返回条数

返回格式

{
  "topViewed": [
    {
      "videoId": "xxxxx",
      "title": "视频标题",
      "channelTitle": "频道名称",
      "publishedAt": "2026-07-22 08:00",
      "viewCount": 123456,
      "likeCount": 1234,
      "commentCount": 56,
      "daysSincePublished": 1.5,
      "velocity": 82304,
      "url": "https://youtu.be/xxxxx"
    }
  ],
  "topRising": [...],       // 同上结构，按日均观看排序
  "totalViewed": 200,
  "totalRising": 150
}

调用示例

curl -X POST {{ api_base }}/api/search \
  -H "Content-Type: application/json" \
  -d '{
    "keywords": ["哪吒", "二郎神"],
    "risingDays": 30,
    "maxPerKeyword": 10
  }'
